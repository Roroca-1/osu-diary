用户名筛选

看别人的 replay / 观战时成绩也会出现在结算画面。这里决定哪些玩家的成绩会被记进日记。 多个用户名用逗号分隔；留空 = 自动只记录你的游戏账号（从 tosu 读取）。

在线拉取 pp（osu! API v2）

本地 rosu-pp 的算法可能落后于官方。在 osu! 账户设置 创建一个 OAuth 应用（回调随意填），填 client ID / secret 与你的 osu 用户 ID，即可按谱面拉取官方 pp（约 1 秒 1 张图）。

导入历史成绩

从 lazer 的 client.realm 回填全部历史成绩（含真实成绩时间与本人账号识别），自动完成 mods 换算； 填了 API 凭证时优先在线拉取官方 pp，否则用 rosu-pp 本地计算。 建议在 osu!lazer 关闭时执行；重复执行不会产生重复记录。

导入旧 CSV

旧版 osu-reading-log.csv（date,ar,bpm,stars,map,mods,acc,miss,notes）。旧 CSV 中被错误记录的日期无法修正。

封面缓存

封面来自 assets.ppy.sh（离线时回退本地谱面背景）。单个封面在打开日历时按需拉取；也可以一次性预热全部。
